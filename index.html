📊 Google 試算表 (Google Sheets) 連動設定中心

自動統計有到 / 未到

利用免費的 Google Apps Script Webhook 服務，每次學生簽到或老師調整點名狀態時，數據皆會同步紀錄於您的 Google 試算表中！

步驟 1：複製並部署 Google Apps Script 程式碼

  1. 開啟您的 Google 試算表。
  2. 點選選單「擴充功能」➔「Apps Script」。
  3. 貼上右方程式碼，點選「部署」➔「新增部署」。
  4. 種類選擇「網路應用程式 (Web App)」，存取對象設定為「所有人 (Anyone)」。
  5. 複製產生的 Web App URL 網址並貼至下方輸入框。

💬 LINE Notify 訊息自動推播串接教學

透過系統內建的 Google Apps Script 後端，您可以免費發送 LINE 訊息通知至老師或班級群組！

  1. 前往 LINE Notify 官網 登入。
  2. 點擊右上角個人名稱 ➔ 點選「發行權杖 (Generate Token)」。
  3. 輸入權杖名稱（如：點名系統通知），選擇要發送的 LINE 群組或個人聊天室。
  4. 將取得的權杖字串加入到您的 Google Apps Script 程式碼中： 
    UrlFetchApp.fetch("https://notify-api.line.me/api/notify", {
  method: "post",
  headers: { Authorization: "Bearer " + LINE_TOKEN },
  payload: { message: "點名提醒：" + studentName + " 已簽到 (" + status + ")" }
});
